# vasl12.github.io

Personal academic website of Vasiliki Sideri-Lampretsa — PhD researcher at the
Technical University of Munich. Live at https://vasl12.github.io/.

Static single-page site with an animated space-themed hero, dynamic publications
from the Semantic Scholar Graph API, and a GitHub Pages projects carousel. No
build step.

## Editing

- `config.js` — name, email, Semantic Scholar ID, GitHub username, site URL.
- `index.html` — all static text (hero, about, education, research cards, contact).
- `styles.css`, `space.css` — visual styling, including the hero animation.
- `script.js`, `scholar-integration.js`, `github-projects.js` — interactive behavior.
- `images/` — profile photo, paper thumbnails, favicons.
